W11D3: MLflow Model Serving & REST API

## Objective
Track five scikit-learn experiments, register the best model,
load the registered model, and serve predictions through a REST API.

## Implemented
- MLflow parameter and metric logging
- Five Random Forest experiments
- Experiment comparison
- Model artifact logging and registration
- Registered model loading and prediction testing
- MLflow REST API serving test
