W11D5: Tracked & Evaluated RAG Pipeline

Project Overview

This project implements a Retrieval-Augmented Generation (RAG) pipeline that retrieves relevant information from a knowledge base and generates answers using a local language model. The pipeline uses LangGraph to manage the workflow, Ragas to evaluate answer quality, CrewAI to review generated answers, and MLflow to track experiments and evaluation results.

Technologies Used

Python — Core programming language

LangGraph — RAG workflow orchestration

Chroma — Vector database for document storage and retrieval

Sentence Transformers — Text embeddings using all-MiniLM-L6-v2

Qwen — Local language models for answer generation and evaluation

Ragas — RAG evaluation

CrewAI — Multi-agent qualitative quality review

MLflow — Experiment tracking and artifact logging

Pandas — Data processing and evaluation result analysis

Google Colab — Development and execution environment

Implementation

1. Knowledge Base Preparation

Created a knowledge base containing information about machine learning, RAG, vector databases, embeddings, chunking, evaluation metrics, MLflow, LangGraph, CrewAI, and Ragas.

2. Document Processing

Split the documents into smaller chunks using RecursiveCharacterTextSplitter to support efficient retrieval.

3. Embeddings and Vector Database

Generated text embeddings using Sentence Transformers and stored the document chunks in Chroma for similarity-based retrieval.

4. RAG Pipeline

Built a LangGraph workflow that:

Accepts a user question.

Retrieves the three most relevant document chunks.

Generates an answer using a local Qwen language model.

Returns the answer and retrieved context.

5. RAG Evaluation

Created a dataset of 10 question-and-answer examples with reference answers and evaluated the pipeline using Ragas.

The evaluation metrics include:

Faithfulness — Measures whether the answer is supported by the retrieved context.

Answer Relevancy — Measures how relevant the answer is to the question.

Context Precision — Evaluates the relevance of the retrieved context.

Context Recall — Evaluates whether the retrieved context contains information needed for the reference answer.

6. CrewAI Quality Review

Used a CrewAI reviewer agent to assess sample RAG outputs for relevance, grounding, unsupported claims, and possible improvements.

7. MLflow Experiment Tracking

Configured MLflow with a SQLite tracking database to record experiment parameters, evaluation metrics, and output artifacts.

Outcome

The project combines retrieval, local answer generation, automated evaluation, qualitative review, and experiment tracking in one RAG workflow. It demonstrates how a RAG system can be built and evaluated using open-source tools in Google Colab.

Conclusion

This project provided practical experience in building a tracked and evaluated RAG pipeline using LangGraph, Chroma, Sentence Transformers, Qwen, Ragas, CrewAI, and MLflow. It also demonstrated how to store evaluation outputs and track experiment results for further analysis and improvement.
